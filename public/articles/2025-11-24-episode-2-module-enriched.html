Enrichissement APIs Cache

Le Module Enriched est le cœur de l'enrichissement des données entreprises. Il orchestre plusieurs sources (INSEE, Pappers, Société.com) pour fournir des données complètes et fiables.

🎯 Problématique

L'enrichissement B2B présente plusieurs défis :

  • Multiplicité des sources : Chaque source a ses propres limites et formats
  • Rate limiting : Les APIs ont des limites de requêtes
  • Qualité des données : Certaines sources sont plus fiables que d'autres
  • Performance : L'enrichissement ne doit pas ralentir l'application

💡 Solution : Orchestration intelligente

J'ai développé un système d'orchestration qui :

  • Groupe les requêtes par domaine : Évite les requêtes redondantes
  • Cache Redis intelligent : Réponses en moins de 0.1s si données en cache
  • Cascade de sources : Si une source échoue, passe à la suivante
  • Rate limiting humanisé : Délais de 5-8s entre requêtes pour éviter les blocages

🔧 Architecture technique

Le module utilise un pattern Factory pour gérer les différentes sources d'enrichissement. Chaque source implémente une interface commune, permettant d'ajouter facilement de nouvelles sources.

📊 Résultats

Avec ce système, l'enrichissement est :

  • Rapide : Cache hit en moins de 0.1s
  • Fiable : Cascade automatique si une source échoue
  • Respectueux : Rate limiting pour éviter les blocages
  • Évolutif : Facile d'ajouter de nouvelles sources

🔄 NOUVEAU : Import CSV Intelligent

Problème résolu : Le module de normalisation ne détectait pas correctement les colonnes CSV, causant 100% d'éléments ignorés lors de l'import.

Solution déployée : Refactorisation complète avec détection automatique intelligente des colonnes :

  • Détection automatique : Reconnaissance de multiples variantes (Entreprise, Société, Nom, Company, etc.)
  • Normalisation intelligente : Transformation automatique vers schéma unifié avant import
  • Recherche multi-champs : Recherche du nom d'entreprise dans plusieurs champs possibles (insensible à la casse)
  • Fallback intelligent : Si nom non trouvé, utilise la première colonne non vide qui ressemble à un nom
  • Nettoyage automatique : Extraction du domaine depuis URLs complètes, suppression de "www."
  • Support multiples encodages : UTF-8, latin-1

Résultats :

  • Avant : 145 éléments ignorés, 0 créés, 0 mis à jour
  • Après : 145 créés, 0 ignorés (100% de succès) ✅
💡 Apprentissage clé : L'orchestration intelligente permet de transformer des APIs limitées en un système robuste et performant. Le cache est votre meilleur ami pour les performances.

🔄 Nouveau : La détection automatique des colonnes transforme l'import CSV d'un processus fragile en une expérience fluide et fiable, même avec des formats de données variés.
