Contexte du projet

Squid Research est une application web moderne conçue pour gérer et optimiser la recherche d'emploi. Elle combine la puissance de Django, l'automatisation de n8n, l'intelligence artificielle de Flowise, et un système d'enrichissement multi-sources pour créer une expérience complète et automatisée de recherche d'emploi.

Fonctionnalités principales

  • 📝 Gestion des candidatures : Suivi complet de vos candidatures avec analytics avancées
  • 🏢 Gestion des entreprises : Base de données enrichie avec Module Enriched (INSEE, Pappers, Societe.com)
  • 🤖 Automatisation intelligente : Relances et suivis automatisés avec IA
  • 🔍 Module Enriched : Enrichissement multi-sources avec cache Redis, orchestration optimisée et rate limiting humanisé
  • 🔎 Recherche LinkedIn : Recherche indirecte de prospects via Google Search, paramétrable par localisation, titre et mots-clés
  • 📧 Email OAuth : Connexion Gmail/Outlook via OAuth, 95% de délivrabilité, tokens chiffrés
  • 🧠 Assistant IA : Optimisation de CV et conseils personnalisés via Flowise
  • 📊 Tableaux de bord : Statistiques et analyses en temps réel
  • 🐳 Architecture Docker : 9 services containerisés (PostgreSQL, Redis, Django, Celery, React, n8n, Flowise, Tor)
  • ✅ Qualité & Tests : 29 tests unitaires (100% réussite), 88% de couverture de code

Architecture technique

🐍 Django (Backend) - API REST, ORM, authentification
⚛️ React (Frontend) - Interface utilisateur moderne
🤖 n8n (Automatisation) - Workflows et intégrations
🧠 Flowise (IA/Chatbot) - LLM et assistants conversationnels
🗄️ PostgreSQL (DB) - Base de données relationnelle
⚡ Redis (Cache) - Cache intelligent pour Module Enriched
🔄 Celery (Worker) - Tâches asynchrones en arrière-plan
🌐 Tor (Proxy) - Anonymat pour scraping
📊 Flower (Monitoring) - Monitoring Celery
🚀 Nginx (Proxy) - Reverse proxy et load balancing

Écosystème & pool d'agents

Squid Research s'inscrit dans un écosystème plus large : un pool d'agents (ce site) relie Squid Research à LPPP-generator (génération de landing pages de candidature) et SquidCommunication (liaison d'information). Qualification des opportunités, enrichissement des données, génération de landings ciblées — le tout supervisé par un cadre « Ne jamais halluciner ».

🐙 Squid Research

Source d'opportunités, entreprises, candidatures. Module Enriched, recherche LinkedIn, OAuth email.

📄 LPPP-generator

Génération automatisée de landing pages pour démarchage (FitClem, 0Flow, Yuwell, Ackuracy).

📢 SquidCommunication

Liaison d'information : contenu, messages, contexte pour cohérence des livrables.
