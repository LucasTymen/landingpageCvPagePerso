🎯 Objectif du projet

Mettre en place des workflows d'acquisition et automatiser les processus métier pour Origin Traiteur. L'objectif principal était de créer un système d'automatisation intelligent pour relancer automatiquement les devis en attente, avec validation multi-canal et suivi en temps réel.

Contraintes : Intégration avec systèmes existants (Gmail, Slack), nécessité de validation humaine, architecture scalable et reproductible.

🛠️ Solutions développées

Système d'agents IA

Développement de 2 agents IA spécialisés pour l'analyse et la rédaction automatique des relances de devis.

  • Agent Analyseur : analyse les devis en attente et identifie les priorités
  • Agent Rédacteur : génère des messages personnalisés pour les relances
  • Intégration Flowise pour la gestion des LLM
  • Validation intelligente avec scoring automatique

Architecture containerisée

Mise en place d'une architecture scalable avec Django + n8n + Flowise en containers Docker.

  • Architecture microservices containerisée
  • Base de données PostgreSQL pour la persistance
  • Orchestration n8n pour les workflows
  • API REST Django pour les intégrations

Validation multi-canal

Système de validation des relances via Gmail et Slack avec tableau récapitulatif interactif.

  • Intégration Gmail API pour l'envoi et le suivi
  • Intégration Slack API pour les notifications
  • Tableau récapitulatif avec actions interactives
  • Suivi en temps réel des relances

CI/CD automatisé

Mise en place d'un pipeline GitLab CI/CD pour les déploiements automatisés et reproductibles.

  • Pipeline GitLab CI/CD complet
  • Déploiements automatisés
  • Tests automatisés avant déploiement
  • Monitoring et alertes en temps réel

Workflows métier

Intégration des workflows métier avec monitoring en temps réel et actions interactives.

  • Workflows n8n alignés avec les processus métier
  • Monitoring en temps réel des performances
  • Tableau de bord interactif
  • Actions manuelles possibles sur les relances
