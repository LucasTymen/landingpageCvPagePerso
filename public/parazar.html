Parazar - Growth Hacking & Automatisation

Projet collectif - 1er de promo (2021)

Growth Hacking Automatisation Data Analytics Python

🎯 Objectif du projet

Développer une solution complète d'automatisation pour la recherche d'emploi dans le secteur tech, en combinant scraping de données, automatisation des candidatures et suivi des performances via un dashboard analytique.

🛠️ Solutions développées

Scraper automatisé

Développement d'un scraper intelligent pour collecter automatiquement les offres d'emploi tech depuis plusieurs plateformes (LinkedIn, Indeed, Welcome to the Jungle, etc.).

  • Technologies : Python, Scrapy, Selenium
  • Gestion des anti-bot et rotation des proxies
  • Filtrage intelligent par mots-clés et localisation

Automatisation des candidatures

Mise en place d'un système de candidature automatisée avec outils no-code pour optimiser le processus de recherche d'emploi.

  • Intégration Zapier et outils no-code
  • Personnalisation des messages de candidature
  • Suivi automatique des relances

Dashboard de suivi

Création d'un dashboard complet pour analyser les performances et optimiser la stratégie de candidature.

  • Base de données SQL pour stocker les données
  • Visualisations avec Looker Studio
  • Métriques : taux de réponse, entretiens, offres
