🎯 Project Objective

Set up acquisition workflows and automate business processes for Origin Traiteur. The main objective was to create an intelligent automation system to automatically follow up on pending quotes, with multi-channel validation and real-time monitoring.

Constraints: Integration with existing systems (Gmail, Slack), need for human validation, scalable and reproducible architecture.

🛠️ Solutions Developed

AI Agent System

Development of 2 specialized AI agents for analyzing and automatically writing quote follow-ups.

  • Analyzer Agent: analyzes pending quotes and identifies priorities
  • Writer Agent: generates personalized messages for follow-ups
  • Flowise integration for LLM management
  • Intelligent validation with automatic scoring

Containerized Architecture

Setup of a scalable architecture with Django + n8n + Flowise in Docker containers.

  • Containerized microservices architecture
  • PostgreSQL database for persistence
  • n8n orchestration for workflows
  • Django REST API for integrations

Multi-Channel Validation

Follow-up validation system via Gmail and Slack with interactive summary table.

  • Gmail API integration for sending and tracking
  • Slack API integration for notifications
  • Summary table with interactive actions
  • Real-time follow-up monitoring

Automated CI/CD

Setup of a GitLab CI/CD pipeline for automated and reproducible deployments.

  • Complete GitLab CI/CD pipeline
  • Automated deployments
  • Automated tests before deployment
  • Real-time monitoring and alerts

Business Workflows

Integration of business workflows with real-time monitoring and interactive actions.

  • n8n workflows aligned with business processes
  • Real-time performance monitoring
  • Interactive dashboard
  • Manual actions possible on follow-ups
