Project context

Squid Research is a modern web application designed to manage and optimize job searching. It combines Django, n8n automation, Flowise AI, and a multi-source enrichment system to deliver a complete, automated job-search experience.

Main features

  • 📝 Application tracking: Full tracking of your applications with advanced analytics
  • 🏢 Company management: Enriched database with Enriched Module (INSEE, Pappers, Societe.com)
  • 🤖 Smart automation: Automated follow-ups and reminders with AI
  • 🔍 Enriched Module: Multi-source enrichment with Redis cache, optimized orchestration and humanized rate limiting
  • 🔎 LinkedIn search: Indirect prospect search via Google Search, configurable by location, title and keywords
  • 📧 Email OAuth: Gmail/Outlook connection via OAuth, 95% deliverability, encrypted tokens
  • 🧠 AI assistant: CV optimization and personalized advice via Flowise
  • 📊 Dashboards: Real-time statistics and analytics
  • 🐳 Docker architecture: 9 containerized services (PostgreSQL, Redis, Django, Celery, React, n8n, Flowise, Tor)
  • ✅ Quality & tests: 29 unit tests (100% pass), 88% code coverage

Technical architecture

🐍 Django (Backend) — REST API, ORM, authentication
⚛️ React (Frontend) — Modern UI
🤖 n8n (Automation) — Workflows and integrations
🧠 Flowise (AI/Chatbot) — LLM and conversational assistants
🗄️ PostgreSQL (DB) — Relational database
⚡ Redis (Cache) — Smart cache for Enriched Module
🔄 Celery (Worker) — Background async tasks
🌐 Tor (Proxy) — Anonymity for scraping
📊 Flower (Monitoring) — Celery monitoring
🚀 Nginx (Proxy) — Reverse proxy and load balancing
