Enrichment APIs Cache

The Enriched Module is at the heart of enterprise data enrichment. It orchestrates multiple sources (INSEE, Pappers, Société.com) to provide complete and reliable data.

🎯 Problem Statement

B2B enrichment presents several challenges:

  • Multiple sources: Each source has its own limits and formats
  • Rate limiting: APIs have request limits
  • Data quality: Some sources are more reliable than others
  • Performance: Enrichment must not slow down the application

💡 Solution: Intelligent Orchestration

I developed an orchestration system that:

  • Groups requests by domain: Avoids redundant requests
  • Intelligent Redis cache: Responses in less than 0.1s if data is cached
  • Source cascade: If one source fails, moves to the next
  • Humanized rate limiting: 5-8s delays between requests to avoid blocks

🔧 Technical Architecture

The module uses a Factory pattern to manage different enrichment sources. Each source implements a common interface, making it easy to add new sources.

📊 Results

With this system, enrichment is:

  • Fast: Cache hit in less than 0.1s
  • Reliable: Automatic cascade if a source fails
  • Respectful: Rate limiting to avoid blocks
  • Scalable: Easy to add new sources

🔄 NEW: Intelligent CSV Import

Problem solved: The normalization module did not correctly detect CSV columns, causing 100% of elements to be ignored during import.

Solution deployed: Complete refactoring with intelligent automatic column detection:

  • Automatic detection: Recognition of multiple variants (Company, Société, Nom, etc.)
  • Intelligent normalization: Automatic transformation to unified schema before import
  • Multi-field search: Company name search in multiple possible fields (case-insensitive)
  • Intelligent fallback: If name not found, uses first non-empty column that looks like a name
  • Automatic cleanup: Domain extraction from full URLs, "www." removal
  • Multiple encoding support: UTF-8, latin-1

Results:

  • Before: 145 elements ignored, 0 created, 0 updated
  • After: 145 created, 0 ignored (100% success) ✅
💡 Key Learning: Intelligent orchestration transforms limited APIs into a robust and performant system. Cache is your best friend for performance.

🔄 New: Automatic column detection transforms CSV import from a fragile process into a smooth and reliable experience, even with varied data formats.
