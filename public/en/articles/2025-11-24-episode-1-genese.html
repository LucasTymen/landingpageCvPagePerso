SquidResearch was born from a simple observation: job searching is time-consuming and repetitive. Why not automate this process while maintaining quality and personalization?

🎯 The Initial Idea

The goal was to create a platform that combines multiple technologies to offer a complete experience: application management, automatic company enrichment, LinkedIn prospect search, and automated follow-ups.

🏗️ Architectural Choices

From the start, I opted for a microservices architecture with Docker. This approach enables:

  • Scalability: Each service can be scaled independently
  • Isolation: Services are independent, facilitating maintenance
  • Flexibility: Easy to add new services (n8n, Flowise, etc.)

🔧 Technical Stack

The choice fell on Django for the backend (robustness, powerful ORM, rich ecosystem), React for the frontend (reusable components, reactive state), and PostgreSQL for the database (reliability, performance, JSON support).

📊 First Challenges

The first challenges were integrating multiple services (n8n, Flowise, Celery) and managing multi-source enrichment. The solution: an intelligent Redis caching system and domain-optimized orchestration.

💡 Key Learning: A well-thought-out architecture from the start avoids costly refactorings later. Taking the time to design the architecture is a profitable investment.
