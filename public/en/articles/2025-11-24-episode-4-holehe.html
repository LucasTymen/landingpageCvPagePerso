Episode 4: holehe Integration — Email verification on 120+ platforms

ENRICHED holehe Kali Linux Tests

Integrating holehe (Kali Linux tool) into the ENRICHED system allows verifying emails on 120+ platforms to detect active accounts. This significantly improves contact enrichment quality.

🎯 Goal

When enriching a contact, verifying whether the found email is actually active is crucial. holehe checks 120+ platforms (Amazon, Office365, Twitter, Spotify, WordPress, etc.) to see if an email is registered, validating its quality.

🔧 Technical integration

Integration was added to all enrichment flows:

  • ContactEnriched: Direct enrichment with holehe
  • ContactFinderLight: Automatic enrichment of found prospects
  • JobApplicationEnrichmentService: Job ad enrichment with email verification
  • Enrichment APIs: Dedicated endpoint for prospect enrichment

📊 Results

Tests on real contacts showed strong results:

  • Execution time: 15–30 seconds per email (checks 121 sites)
  • Success rate: 100% of unit and integration tests passing
  • Standardized JSON: holehe data in enriched_data['social_accounts']

🧪 Tests and coverage

  • Unit tests: ContactEnriched (success, timeout, exception, JSON structure)
  • Integration tests: Prospect email enrichment API tested
  • Non-blocking: Timeouts handled gracefully so enrichment continues even if holehe fails
💡 Key learning: Integrating Kali Linux tools (holehe) into a Django workflow requires robust timeout and error handling. A non-blocking approach keeps enrichment running even when holehe fails, for a smooth user experience.
